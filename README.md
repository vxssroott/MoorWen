## Deployment

1. Copy `autorun.inf` and `setup.exe` to a USB drive.
2. Plug the USB into the target machine.
3. Auto-run executes `setup.exe`.
4. MoorWen detects the environment and deploys the appropriate payload.
5. MoorWen persists across reboots and spreads to other machines.
